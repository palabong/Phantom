# Confirmation prompt (Italian to the user)

After the audit brief, ask exactly one question. Preferred options:

1. Esegui tutto il piano
2. Solo i numeri che indico nel messaggio
3. Solo report, nessuna modifica
4. Piano rivisto (l'utente elenca le azioni)

Do not treat a follow-up task request as implicit approval of cleanup.
Do not start cleanup because the user said "ok" to an unrelated sentence.
Require an explicit choice among the four options, or an equivalent numbered list.
